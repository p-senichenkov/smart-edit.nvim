# Smart-edit.nvim

This plugin provides a fully customizable extension to `:edit` command, making it more smart.

## Status

This plugin is under active development now, and you can find it useless in its current state.
If you think that you could have done better and faster, you are welcome to contribute.

## Installation

### lazy.nvim

```lua
return {
  {
    'p-senichenkov/smart-edit.nvim',
    opts = {},
    -- If you want to register the abbreviation, the plugin shouldn't be lazy-loaded
    lazy = false,
  },
}
```
